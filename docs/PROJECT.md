## 1. تفاصيل المشروع

LogiBridge منصة وسيطة رقمية بين تركيا وسوريا، تربط:
- التجار والمستوردين والمصدّرين
- شركات النقل وأصحاب الشاحنات (وسائقيهم)
- المخلّصين الجمركيين
- مزوّدي المعدات والمورّدين
- الأفراد الذين يحتاجون شحن حمولة صغيرة

الهدف: بديل رقمي لعمل شركات الفوروردينغ التقليدية، بسوق مفتوح للعروض، وملف شحنة واحد، ومتابعة وتوثيق، وحالة المعابر والقوانين.

**الكتلة المستهدفة للإطلاق:** طريق واحد أو طريقان أولًا (مثل غازي عنتاب ⇄ حلب عبر باب السلامة أو الراعي، وهاتاي ⇄ إدلب عبر باب الهوى)، ثم التوسع. التفاصيل في `docs/project/LogiBridge-launch-plan.md`.

**الوضع المالي:** اشتراك شهري للشركات بعد فترة مجانية (تاجر 29$، ناقل 19$، مخلّص 19$، مورد 15$، الأفراد مجانًا)، بدون عمولة على الشحنات.

**اللغات:** العربية (RTL) والإنكليزية والتركية.

## 2. المخطط التقني (Blueprint)

### المكدس (Stack)
| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 + Vite 7، CSS مخصص (`src/*.css`) |
| الخادم | Node.js + Express 5 (`server/`) |
| التخزين | ملف JSON محلي للتطوير، Netlify Blobs أو PostgreSQL أو Redis حسب البيئة |
| الاستضافة | Netlify (الواجهة + Functions في `netlify/functions/`) |
| الجدولة | `netlify/functions/emails.mjs` كل 10 دقائق (الإيميلات، تتبع الشحنات، مراقبة القوانين الشهرية، الإغلاق التلقائي) |
| تطبيق السائق | Capacitor (Android) في `mobile/`، وبناء APK تلقائي عبر GitHub Actions |
| الخرائط | Leaflet + OpenStreetMap |
| الملفات | pdf-lib (تحويل PNG إلى PDF، العلامة المائية)، exceljs (تقارير Excel) |
| الاختبار | `node --test tests/*.test.js` |

### الخدمات الخارجية (تُضاف بمتغيرات بيئة على Netlify، لا بالكود)
- **البريد:** Resend (`RESEND_API_KEY`، `MAIL_FROM`، `MAIL_REPLY_TO`)
- **واتساب:** WhatsApp Cloud API (`WHATSAPP_TOKEN`، `WHATSAPP_PHONE_ID`، `WHATSAPP_TEMPLATE`، `WHATSAPP_LANG`)
- **الدفع:** PayTR (`PAYTR_MERCHANT_ID`، `PAYTR_MERCHANT_KEY`، `PAYTR_MERCHANT_SALT`، `PAYTR_TEST_MODE`)
- **المساعد الذكي:** Anthropic (`ANTHROPIC_API_KEY`)، اختياري
- **الإدارة:** `ADMIN_EMAIL`، `ADMIN_PASSWORD`، `DEMO_MODE` (مغلق افتراضيًا)

### خريطة الكود
- `server/` — الخادم والمسارات: `index.js` (المسارات الرئيسية)، `store.js` (التخزين)، `identity.js` (تشفير الوثائق AES-256-GCM والتحقق منها)، `advanced.js` (الإشعارات)، `email.js`، `whatsapp.js`، `support.js` (المساعد)، `documents.js`، `payments.js`، `drivers.js`، `operations.js` (لوحة المسؤول والنسخ الاحتياطي)، `ruleWatch.js` (مراقبة القوانين)، `fileOutput.js`، `watermark.js`، `world.js` (عزل البيانات التجريبية)
- `src/` — الواجهة: `main.jsx` (التطبيق الرئيسي)، `Landing.jsx`، `AccountAccess.jsx` (التسجيل والدخول)، `Operations.jsx` (لوحة المسؤول)، `Verification.jsx` (التوثيق)، `Tracking.jsx` و`Gps.jsx` (التتبع)، `Drivers.jsx`، `AdminTools.jsx` (سجل الأخطاء والمهام)، `Profiles.jsx` (الملفات والنسخ الاحتياطي)، `BorderRules.jsx`، `theme.css` (الألوان الكحلي والذهبي)
- `shared/` — منطق مشترك بين الخادم والواجهة: `countries.js`، `workspaces.js` (وحدات كل نوع حساب)، `borderSources.js`، `contact.js`، `legal.js`، `routes.js`، `wa.js`
- `netlify/functions/` — `api.mjs` (نقطة الـ API)، `emails.mjs` (المهام المجدولة)
- `tests/` — 64 اختبار ناجحًا (آخر تشغيل)

### أنواع الحسابات ووحداتها
| النوع | الوحدات الأساسية |
|---|---|
| تاجر / مستورد / مصدّر | طلب شحن، شحنات، شحنات متكررة، تتبع، مجموعات، مخلّص، حدود، تقييمات، سوق، عقود، تقارير، تكامل، رحلات عودة، أسعار |
| شركة نقل | وظائف النقل، الأسطول، المجموعات، التتبع، السائقون، التقارير، رحلات العودة، الفريق |
| مخلّص جمركي | وظائف التخليص، التتبع، الحدود، العقود، الفريق |
| مورد معدات | المخزون، الطلبات، التقويم، الفريق |
| فرد | شحن شخصي، توثيق الجواز، رحلات العودة |
| مسؤول | لوحة عامة، الحسابات، تقرير الحسابات، النمو، التقييمات والشكاوى، ملاحظات، الحدود، الوثائق |

الحسابات غير الموافق عليها ترى الدفعات الأولى فقط (لوحة، دليل، ملف، توثيق، دعم، أمان).

### مبادئ ثابتة
- **الوثائق مشفّرة** عند التخزين، ومعروضة للطرف المعني فقط، مع علامة مائية عند التنزيل من طرف آخر.
- **البيانات التجريبية معزولة** كليًا عن الحسابات الحقيقية.
- **المنصة وسيط تقني فقط**، ولا تحفظ أموال الشحنات قبل ترتيب قانوني ومصرفي واضح.
- **لا أرقام مزيّفة** في الصفحات العامة، ولا تقييمات أو شهادات مختلقة.
- **القوانين لا تُنشر تلقائيًا**: مراقبة شهرية تنبّه المسؤول فقط.
- **المفاتيح وكلمات السر** تُوضع في إعدادات Netlify، ولا تُرسل في الدردشة أو الكود.

### حالة الميزات الحالية
- **مكتمل ومرفوع:** العناصر أعلاه.
- **مكتمل محليًا، بانتظار النشر على Netlify:** لا شيء معلّق في الكود.
- **مفتوح:**
  1. ظهور الأفراد بانتظار المراجعة في قائمة طلبات الهوية: لم يُعرف السبب في الكود بعد، يحتاج تجربة تسجيل فرد من البداية.
  2. تبسيط صفحات التسجيل (حذف النصوص الزائدة والتكرار وذكر المساعد الذكي).
  3. ما الذي تضيفه «إعدادات الموقع» (غير محدد بعد).
  4. إرسال واتساب الموافقة للحسابات غير المشتركة: قرار خصوصية يحتاج تأكيدًا.
  5. التحقق من ملف JPG (620 KB) ظهر فارغًا لدى المستخدم، والنسخة الأصلية تحتاج فحصًا.

### إجراءات يقوم بها المالك (خارج الكود)
- ضبط متغيرات Netlify: `ANTHROPIC_API_KEY`، واتساب، `RESEND_API_KEY` و`MAIL_FROM` بعد ربط الدومين، PayTR.
- إيقاف شعار «Powered by Netlify» من Project configuration ← General.
- تشغيل Trigger deploy عند إيقاف النشر التلقائي.
- تغيير إيميل المسؤول حسب `docs/project/LogiBridge-manual-steps.md`.
