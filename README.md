# LogiBridge — جسور اللوجستيات الذكية

إضافات 4 أكتوبر 2026: روابط السائقين، تقويم التأجير، طلب التأمين، التقدير والمطابقة، العملات، التقارير، API، الإشعارات والتسويات. راجع [دليل التشغيل الجديد](ADVANCED.md) للتجربة وحدود كل وظيفة؛ هذا التحديث يحدّث وصف الوظائف القديمة أدناه.

للوصول المباشر إلى إدخال الشحنات ورفع الوثائق والتتبع ولوحة المسؤول الفعلية، راجع [دليل الوظائف والتجربة الإدارية](OPERATIONS.md). بيانات دخول المسؤول المحلي محفوظة في `data/admin-access.txt`.

الموقع الرئيسي الآن يربط التسجيل والدخول بمساحة العمل والتوثيق. نماذج التحقق تدعم تركيا وسوريا و249 بلدًا ومنطقة بأسماء مترجمة وبحث. التوثيق الدولي مراجعة يدوية حاليًا، وليس ربطًا حكوميًا آليًا.

تحديث الحسابات: تصميم بالأزرق والأصفر، وصفحات دخول مستقلة وتسجيل بكلمة مرور، ومراجعة مستندات الشركات وجوازات الأفراد. اقرأ [دليل الحسابات والتوثيق](ACCOUNTS.md) لإعداد المسؤول واستخدام المسارات الجديدة.

نسخة MVP تجريبية محلية مبنية على «مشروع منصة اللوجستيات الذكية.pdf». الواجهة React مع Tailwind CSS، والخادم Node.js / Express، وخدمة اختيارية Python / FastAPI للذكاء الاصطناعي. تدعم العربية والإنجليزية والتركية واتجاه RTL للعربية، وتصميمًا متجاوبًا للهاتف.

## التشغيل السريع على Windows

المطلوب: Node.js 22 أو أحدث.

```powershell
cd C:\EILAF\proje
npm.cmd install
npm.cmd run dev
```

افتح `http://localhost:3000`. اختر حساب التاجر أو الناقل أو مورّد المعدات أو الفرد أو المسؤول. كل الحسابات والبيانات والشارات الأولية تجريبية. لا تستخدم مستندات شخصية أو حقيقية في العرض التجريبي.

للتحقق والتشغيل بعد البناء:

```powershell
npm.cmd test
npm.cmd run build
npm.cmd start
```

## ما يمكنك تجربته

1. بحساب التاجر، انشر طلب شحن يحدد المدن والوزن والحجم والمعبر والتاريخ.
2. بدّل إلى حساب الناقل، افتح الشحنات وقدّم عرض سعر ومدة نقل. يمكنك إضافة مركبات ورحلات ذات مساحة مشتركة في صفحة الأسطول.
3. بدّل إلى التاجر، قارن العروض واقبل عرضًا ثم اضغط «إيداع ضمان تجريبي».
4. من حساب الناقل، ابدأ النقل ثم أكّد الوصول.
5. من حساب التاجر، أكّد الاستلام. تتحول حالة الضمان إلى «محرر للناقل» مع عرض عمولة تجريبية 3% وصافي الناقل. يمكن للطرفين تقييم الشحنة بعد الاستلام.
6. جرّب حجز حجم من رحلة LCL. يُحفظ الحجز وتُخصم المساحة فورًا، وتُرفض الحجوزات التي تتجاوز السعة حتى عند وصول طلبات متزامنة.
7. ارفع ملف سجل تجاري تجريبي؛ يراجعه المسؤول يدويًا وينزله ويقبله أو يرفضه. الشارة لا تُمنح بمجرد الاشتراك Pro.
8. أرسل رسالة بين حسابين، وتابع قائمة تحضير الوثائق لكل معبر. تُحفظ مربعات الاختيار لكل مستخدم ومعبر.
9. من حساب المسؤول، أظهر أو أخفِ التتبع والتقييمات والسوق والعقود. تُمنع العمليات الخاصة بالوحدات المعطلة من الخادم أيضًا.
10. يستطيع المورّد إضافة عروض معدات بيع أو إيجار، ويمكن للمستخدم إنشاء حجز تجريبي. تبديل Free / Pro تجريبي ولا يُنشئ اشتراكًا مدفوعًا.

## حفظ البيانات والبنية

- يعمل الوضع الافتراضي دون خدمات خارجية. تُحفظ البيانات في `data/state.json` وتبقى بعد إعادة تشغيل الخادم. الجلسات في الذاكرة؛ تعود إلى تسجيل الدخول بعد إعادة التشغيل.
- تُنفذ التغييرات المحلية في طابور متسلسل، وتُحفظ إلى ملف مؤقت ثم يُستبدل الملف الأساسي لتجنب تعارض الكتابات. هذا المسار لخادم واحد.
- عند تحديد `DATABASE_URL` تُحفظ الحالة في PostgreSQL داخل جدول `logibridge_state` بصيغة JSONB. هذه بنية أولية، وليست مخطط معاملات تجاريًا مطبعًا؛ قبل تشغيل عدة نسخ من الخادم يجب تحويلها إلى جداول وعلاقات ومعاملات وقفل على مستوى قاعدة البيانات.
- عند تحديد `REDIS_URL` تحفظ الجلسات في Redis مع مدة صلاحية يوم واحد. ليس هناك تخزين مؤقت للرسوم الجمركية.
- إعداد Docker Compose يضم Express وPostgreSQL وRedis وFastAPI. المنافذ العامة مقيدة بالعنوان المحلي. قيم كلمات المرور الافتراضية للتطوير المحلي فقط.

```powershell
docker compose up --build
```

يتطلب هذا المسار Docker Desktop. لم يتم تشغيل خدمات Docker في بيئة التسليم.

## خدمة الذكاء الاصطناعي الاختيارية

انسخ `.env.example` إلى `.env` وأدخل مفاتيحك على جهازك. لا تحفظ `.env` في Git ولا تدخل المفاتيح في الواجهة.

المتغيرات المطلوبة للربط: `AI_SERVICE_URL` و`AI_SERVICE_KEY` و`OPENAI_API_KEY`. يجب أن تتطابق قيمة المفتاح الداخلي في الخادمين. النموذج قابل للتغيير عبر `OPENAI_MODEL`.

إذا توفر Python 3.12:

```powershell
python -m pip install -r ai/requirements.txt
python -m uvicorn ai.main:app --env-file .env --host 127.0.0.1 --port 8000
node --env-file=.env server/index.js
```

تنبيه تشغيلي: `uvicorn --env-file` يحتاج `python-dotenv` المدرجة ضمن المتطلبات. يوفر Docker Compose بديلًا بتحميل البيئة دون Python محلي.

عندما لا تكون الخدمة متصلة، تُرسل الرسالة الأصلية مع توضيح أنها لم تُترجم، ويعيد المستشار قائمة تحضير عامة دون اختلاق رمز HS أو رسوم. خدمة الذكاء الاصطناعي عند ربطها تقدم ترجمة وتحضيرًا أوليًا؛ لا تتصل بمصادر تشريعات أو تعرفة جمركية حديثة، لذا لا تقدم حكمًا رسميًا. الحاسبة تضرب قيمة البضاعة بالنسبة التي يُدخلها المستخدم بنفسه، وليست حاسبة رسوم رسمية.

## الحدود المتبقية قبل إطلاق تجاري

| البند | ما تم تنفيذه | ما يحتاج ربطًا أو تطويرًا |
|---|---|---|
| الموقع والهاتف | موقع متجاوب بثلاث لغات | تطبيق أصلي Android / iOS، إشعارات ومزايا دون اتصال |
| الحسابات | صفحات مستقلة، خمسة حسابات عرض، تسجيل محلي وكلمات مرور scrypt وجلسات وحد محاولات أولي | تأكيد البريد وMFA وحماية موزعة واستعادة الحساب |
| الشحن والعروض | نشر، مقارنة، قبول، حالات نقل وتقييم مزدوج | إدارة تجارية متقدمة وأساطيل متعددة وشركات متعددة ومناقصات موسعة |
| التوثيق | نماذج للسجل والجواز، ملفات مشفرة ومراجعة بشرية مع مرجع وقرار | ربط رسمي وفحص أصالة وملفات وإدارة مفاتيح واحتفاظ إنتاجية |
| الجمارك | قائمة تحضير عامة وحاسبة افتراضية؛ موصل AI اختياري | قواعد موثقة ومحدثة لكل معبر وتصنيف HS مُراجع ورسوم رسمية |
| LCL | نشر رحلة، حجز مساحة، منع تجاوز السعة | تحسين التجميع آليًا بحسب التواريخ والمسارات وطبيعة البضاعة |
| التواصل | رسائل محفوظة بين حسابين؛ موصل ترجمة | رسائل فورية عبر WebSocket وإشعارات وترجمة مُختبرة بمفتاح حقيقي |
| WhatsApp / SMS | سجل تحديثات محلي واضح الحالة | Twilio أو WhatsApp Business، أرقام وموافقة المستلمين وقوالب إرسال وإعادة المحاولة |
| الدفع والعمولات | آلة حالات ضمان وعمولة واسترداد تجريبي | مزود دفع/ضمان مالي مرخص وربط Webhooks وتسويات مالية فعلية |
| الاشتراكات | تبديل خطط تجريبي | اشتراكات مدفوعة وصلاحيات ومزايا Pro فعلية وفواتير |
| السوق | عروض بيع وإيجار وحجوزات تجريبية | دفع، مخزون، توصيل، تأمين إيجار ومدد وتوفر |
| العقود | إقرار تجريبي محفوظ بالاسم والتاريخ | توقيع رقمي معتمد، رفع وتدقيق مستندات الشحن، سجل إثبات قانوني |

الوضع الافتراضي يستمع إلى `127.0.0.1` لتشغيل العرض محليًا. `DEMO_MODE=false` يعطل دخول حسابات العرض؛ تعمل الحسابات المسجلة لكنه لا يجعل التطبيق جاهزًا للإنتاج تلقائيًا. قبل النشر: أكمل المصادقة، معاملات قاعدة البيانات، النسخ الاحتياطية، مراقبة الأخطاء وHTTPS. لم تُنفذ أي عملية دفع أو إرسال رسالة خارجية أو رفع مستند إلى خدمة خارجية.

## الملفات الرئيسية

- `src/main.jsx`: الواجهات وسير الاستخدام.
- `src/i18n.js`: نصوص الواجهة باللغات الثلاث.
- `src/style.css`: التصميم والاستجابة للشاشات المختلفة.
- `server/index.js`: واجهات API والتحقق من الجلسة والصلاحيات.
- `server/domain.js`: قواعد العروض والسعة وحالات الضمان.
- `server/store.js`: التخزين المحلي أو PostgreSQL.
- `ai/main.py`: موصل الذكاء الاصطناعي الاختياري.
- `tests/`: اختبارات قواعد العمل واختبارات HTTP متكاملة.

راجع `IMPLEMENTATION.md` لنتائج التحقق وحدود التسليم.
